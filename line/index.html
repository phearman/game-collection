🎮 在 LINE 裡也能找到遊戲集錦

LINE 小幫手使用說明

「遊戲集錦回饋」是我們的 LINE 小幫手，可以開遊戲、收意見、查自己的成績與群組排行，也能查天氣、送問候和說笑話。

加好友

手機點「加好友」即可開啟 LINE；電腦瀏覽時，請用手機開啟本頁後點「加好友」。

快速開始指令總表與範例群組使用須知常見問題

3 步快速開始

  1. 點上方「加好友」，開啟「遊戲集錦回饋」的私訊。
  2. 先傳 #功能（也可用 #介紹）認識小幫手，或傳 #說明 查看可用指令與用法。
  3. 試著傳 #遊戲，點回覆卡片上的「開始玩」，就能開啟遊戲。

以下對話與卡片都是簡化示意；小明、小美及分數、天氣皆為範例資料，並非即時資訊。泡泡裡的選項僅供示意，請到 LINE 操作。

指令總表與對話範例

「兩者」指私訊與已核准群組。指令的 # 可用半形或全形；指令和內容、縣市之間請留一個空白。

🎮 遊戲

#遊戲兩者
挑選遊戲或進大廳；「開始玩」會用外部瀏覽器開啟網站，不必登入也能玩。

💬 意見回饋

直接私訊文字私訊
直接告訴我們想法，送出就會記錄為回饋；一般問候「早安」「午安」「晚安」不收。
#回饋 內容兩者
群組用 #回饋 加內容，或 @ 小幫手後傳「回饋 內容」才會收取。每天最多 20 則文字回饋；目前不收圖片、貼圖或語音。
取消 / #取消私訊
不想繼續回饋時，整則傳「取消」。這則取消訊息不會記錄；不會刪除已送出的回饋。
收回原訊息兩者
長按原本送出的回饋，選 LINE 的「收回」；收到收回通知後，就會刪除那則回饋。只在自己手機上「刪除」訊息不會撤回。

🏆 成績與排行

#綁定私訊
點綁定按鈕 → 用平常玩遊戲的 Google 或 GitHub 帳號登入 → 網站按「確認綁定」。連結 10 分鐘內有效、只能用一次；不要分享。群組輸入只會提醒改用私訊。
#成績兩者
綁定後看自己的等級、XP、總局數與最佳分數。群組查詢會讓該群成員看到你的成績卡。
#解除綁定私訊
解除帳號連結並退出所有群組排行；也可到我的紀錄解除 LINE 綁定。
#加入排行群組
先私訊綁定，再在已核准群組自行加入；每個群組都要各自加入。
#排行群組
看本群近 7 天 XP 前 10 名，依每人最近 50 局計算，可能不涵蓋七天全部遊玩。
#排行 2048群組
看指定遊戲的最佳分數前 10 名；可換成其他遊戲名稱。沒加入本群排行的人不會列出。
#退出排行群組
只退出目前群組，保留綁定與其他群組的排行資格。

☀️ 生活小幫手

#天氣 [縣市]兩者
查今明 36 小時預報，例如 #天氣 高雄。私訊省略縣市沿用上次查詢，首次預設高雄市；群組預設高雄市。新竹、嘉義請寫市或縣。
#早安兩者
早安問候、台灣時間與天氣提醒。
#午安兩者
午安問候、台灣時間與天氣提醒。
#晚安兩者
晚安問候、台灣時間與天氣提醒。問候要加 # 或在群組 @ 小幫手才會回應；群組問候使用高雄市天氣。
#笑話 [分類]兩者
抽未看過的上架笑話，可指定物品、動物、校園、諧音、生活、益智、食物、自然、語文或急轉彎，例如 #笑話 自然。未指定分類不抽急轉彎。看完該分類會重新開始；有出處以小字標示。按三鍵給 1～3 分，重按覆蓋分數。
#急轉彎兩者
先抽機智問答題目，按「看答案」才揭曉答案並評分；也可用 #笑話 急轉彎。看答案只限自己抽到的題目。抽題計生活次數，看答案不另計次。資料庫失效時暫停新分類與急轉彎出題，原五類仍有備援但不能評分。
#笑話排行兩者
近 30 天至少 3 人評分的前五名，顯示平均分、評分人數與出處；急轉彎只顯示題目。
#投稿 內容兩者
投稿 10～200 字笑話，不含網址、電話或 email。每人每天最多 3 則，預設生活分類，管理者審核後才上架。
#新聞兩者 準備中
目前只回「新聞功能準備中」，暫時沒有新聞標題或連結。

生活指令每人每天共 30 次，私訊與群組合計，台灣午夜重算；失敗也計次，新聞準備中不計次。不主動推播。

快速選項最後都有「👋 先這樣」，按下送出「先這樣」後 LINE 會收起選項；私訊或已核准群組直接傳「先這樣」（或 @ 小幫手後傳）也可以，不會回覆、不記錄、不計次。

❓ 說明

#功能 / #介紹兩者
用分類卡片認識小幫手，含笑話題庫與急轉彎；按「試試看」送出指令，按「看用法」查看 #說明。依場合顯示可用功能，不計生活次數、不記錄為回饋。
#說明 [指令]兩者
不帶指令看清單，帶指令看用法，例如 #說明 天氣、#說明 #排行；也可用 #指令 或 #help。方括號表示可省略，不必真的輸入。
@遊戲集錦回饋群組
在已核准群組用 LINE 的 @ 選到小幫手，後面可接不帶 # 的指令，例如「天氣 台北」。只 @、接「介紹」或無法辨識時回功能介紹；@ 其他人不回應。

群組使用須知

  • 邀請小幫手後，要由遊戲集錦管理者核准群組才會回應；尚未核准時，傳指令也不會收到回覆。
  • 一般聊天不會被記錄，只有 #回饋 加內容或 @ 小幫手後傳「回饋 內容」才會成為回饋。
  • 一個群組只能有一個官方帳號；若已有其他官方帳號，請先確認是否能加入小幫手。
  • #成績 只顯示發出指令者自己的成績；#排行 只列出自行 #加入排行 的人。綁定後不會自動加入。
  • 群組的成績卡與排行會公開給該群成員。只想自己看成績，請私訊 #成績。

常見問題

小幫手怎麼沒回應？

先確認好友已加入、訊息有送出。群組需要遊戲集錦管理者核准；遊戲與生活指令前要有 #，或在群組用 LINE 的 @ 選到小幫手再接指令。綁定、解除綁定和取消請改用私訊。一般聊天、@ 其他人與貼圖不會當作指令回覆；可傳 #功能 認識小幫手。生活指令達每日上限或服務暫時失敗時，請依提示稍後再試。

綁定時要登入哪個帳號？

用平常在遊戲集錦保存紀錄的 Google 或 GitHub 帳號。登入後核對 LINE 與網站名稱，再按「確認綁定」。未登入遊玩只存在裝置上的紀錄，需先在網站登入並完成紀錄合併，才有雲端成績可查。綁定連結過期就回私訊重傳 #綁定。

怎麼刪除我的回饋？傳「取消」可以嗎？

請在 LINE 長按原訊息選「收回」，收到收回事件後會刪除那則回饋。取消只表示這次不繼續回饋，不會刪掉先前送出的意見。無法收回時可請管理者協助；LINE 回饋不顯示在網站「我的紀錄」。

會不會讀取或記錄我的聊天？

小幫手會接收所在對話的訊息事件，但一般群組聊天不保存、不記錄內容。私訊的一般文字會當作回饋保存，請不要傳個人資料；遊戲、說明等指令不當回饋，天氣會記住私訊選的縣市。詳細資料用途請看隱私權政策。

使用小幫手要不要錢？

目前免費，玩遊戲也不需要付費；使用 LINE 與開啟網站會用到自己的網路流量。回饋與生活指令各有每日次數上限。

已綁定，為什麼排行看不到我？

還要在想參加的已核准群組傳 #加入排行，各群分開加入。指定遊戲排行需有該遊戲的雲端最佳分數，且卡片只顯示前 10 名。#退出排行 只退出目前群組；#解除綁定 會退出所有群組。

天氣怎麼一直是高雄？新聞怎麼沒有內容？

第一次查天氣或在群組省略縣市時預設高雄市。可傳 #天氣 台北 指定縣市，私訊下次會沿用；群組不改私人偏好。新聞功能仍在準備中，目前不提供新聞內容。
