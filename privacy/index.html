隱私權政策

最後更新:2026-10-18

簡單說

  • 不登入也能玩,紀錄只存在你自己的瀏覽器裡。
  • 登入可讓不同裝置看到同一份紀錄,也可送出意見回饋;會用到你的顯示名稱、頭像、遊戲紀錄與你送出的意見。
  • 不放廣告、不做追蹤,也不會分享或出售你的資料。

沒有登入時

遊戲紀錄(分數、最佳紀錄、經驗值、成就、進行中的存檔)和設定(深淺色、難度)只存在這台裝置的瀏覽器儲存空間,不會傳到任何伺服器。清除瀏覽器的網站資料,這些紀錄就會一起清掉。

登入後

你可以用登入畫面提供的 GitHub 或 Google 帳號登入。登入後:

  • 我們使用的資料:登入帳號提供的顯示名稱與頭像(顯示在「我的紀錄」),以及你的遊戲紀錄。
  • 存在哪裡:遊戲紀錄存在 Supabase 雲端資料庫(資料中心位於南韓首爾)。資料庫設定成每個帳號只能讀寫自己的紀錄。
  • Email:登入服務(Supabase 的帳號系統)會記錄你登入用的 email,用來辨認是同一個帳號;遊戲集錦本身不把 email 存進遊戲紀錄,也不會顯示或使用它。
  • 登入狀態:為了不必每次重新登入,登入憑證會存在這台裝置的瀏覽器;登出時刪除。

意見回饋

網站管道需登入後才能送出意見回饋。我們會儲存回饋內容、類型、遊戲、版本、網址路徑、裝置類型(手機、平板或電腦)與時間,並和你的帳號連結,用來改善遊戲。除了你可在「我的紀錄」看到自己送出的意見與狀態,只有管理者能查看全部回饋與送出者的顯示名稱。

回饋不另存 email、IP 或瀏覽器指紋;網址只記路徑,不記查詢參數。請不要在內容中填入 email 或其他個人資料。為防止大量送出,資料庫另保留每個帳號最近送出時間與當日次數,不保留額外的回饋內容;清除回饋不會重設當日上限。

你可以在「我的紀錄」清除自己的回饋,或到下方 GitHub Issues 要求刪除。

LINE 管道

指令與對話範例請看LINE 小幫手使用說明。

私訊官方帳號的文字除遊戲、綁定、成績、排行、生活指令、揪團指令、工作回報、交辦、提醒、約與參加測試指令、管理指令、取消詞及整則無井號的「早安」「午安」「晚安」外都視為回饋;群組或多人聊天室只有在管理者核准後,才收取以「#回饋」或「＃回饋」開頭的文字。關鍵字後需接空白、換行或結尾,空內容不保存。文字最多保存 1000 字,超過會截斷並標示。圖片、貼圖、影片、語音與檔案目前不收,不下載也不保存。

LINE 生活指令(#天氣、#早安、#午安、#晚安)會依你的 LINE 使用者識別碼記住私訊上次查詢的縣市,不記錄其他訊息內容;另保留每日使用次數與事件識別碼以限制用量和避免重複回覆,只在你發出指令時回覆,不主動推播。

我們會儲存回饋文字、管道、類型、處理狀態與時間,以及 LINE 使用者識別碼、群組或聊天室識別碼、訊息識別碼、來源類型與顯示名稱快照,用來改善遊戲。LINE 回饋與來源資料只有管理者看得到;回饋本身不和網站帳號綁定,不出現在「我的紀錄」。不記錄一般群組聊天;未核准群組出現指令或成員加入事件時,只保存群組或聊天室識別碼與首次／最後時間,供管理者核准。

你可在 LINE 收回原訊息,系統收到收回事件後會刪除回饋、來源與處理歷程;也可請管理者刪除,透過下方 GitHub Issues 提出時請勿公開個人識別碼。為避免重送讓已收回內容復原,系統會保留不含內容的事件去重及收回識別碼;每日配額只保存識別碼、日期與次數,刪除回饋不重設配額。

LINE 綁定與群組排行

私訊「#綁定」可取得 10 分鐘內有效的一次性連結;資料庫只保存代碼的 SHA-256 雜湊、LINE 使用者識別碼、顯示名稱、到期與使用時間。登入網站並按「確認綁定」後,保存 LINE 使用者識別碼、網站帳號識別碼、LINE 顯示名稱快照與綁定時間。一個 LINE 和網站帳號各只能綁定一個對象;重新綁定會取代原綁定並退出原有排行。不要分享綁定連結。

私訊「#成績」可以看自己的等級、XP、總局數與最佳分數。在已核准群組使用「#成績」時,自己的成績卡會公開給該群組成員。

群組排行只列出自己在該群打「#加入排行」的人,保存群組識別碼、LINE 使用者識別碼、顯示名稱快照與加入時間。各群獨立,顯示近 7 天 XP 或指定遊戲的最佳分數前 10 名;XP 依每人最近 50 局紀錄計算,可能不涵蓋七天全部遊玩。下指令或加入排行時會更新顯示名稱快照。

在群組打「#退出排行」可退出該群;私訊「#解除綁定」或在「我的紀錄」按「解除 LINE 綁定」,會同時退出所有群組排行。清除雲端紀錄或刪除網站帳號也會清除綁定與排行。一般聊天不記錄,綁定成功不另發通知或主動推播。

LINE 群組揪團

在已核准群組使用「#揪」開團或「+1」報名，會記錄群組識別碼、團號、標題、發起人的 LINE 使用者識別碼與暱稱、截止時間及名額。參與者會記錄 LINE 使用者識別碼、暱稱與加入時間；暱稱以 LINE 群組成員資料取得，失敗顯示「匿名成員」。名單與開團卡會公開給該群組成員，回覆不顯示個人識別碼。

截止前可用「-1」取消並移除自己的報名。結束 30 天後刪除參與者資料、提醒識別碼與發起人識別及暱稱；由後續揪團指令順手清理，沒有請求時會延後清理。不含個人識別的團號及標題仍保留，請勿在標題填入個人資料。每日開團配額只保留當日識別碼與次數，下次揪團請求會清除舊日配額；事件去重紀錄不含訊息內容或使用者識別碼。

正常加入或取消不回覆，首次滿額與截止後第一次互動才公布；不主動推播。資料獨立於網站帳號，解除綁定或清除網站雲端紀錄不會自動刪除。也可透過 LINE 私訊要求刪除，請勿在公開留言貼出識別碼。

每日挑戰

每日挑戰需登入，每天的數獨、踩地雷與翻翻樂完成秒數、踩地雷是否踩雷、翻翻樂失誤數、開始與完成時間及結果會和你的帳號連結，保留 35 天；以台灣午夜換日。Wordle 舊每日成績在改版後依 35 天規則自然清除。只有你在『我的紀錄』自行打開公開時,你的暱稱、排行頭像與今天的成績才會出現在網站今日排行;預設不公開,可隨時關閉。公開設定與暱稱存在你的帳號,關閉後立即從排行移除;清除雲端紀錄或刪除帳號時一併刪除。

只有你自行在已核准的 LINE 群組使用「#加入排行」後，才會在該群組的「#今日挑戰」排行顯示 LINE 名稱與當日成績；綁定須早於當天台灣時間 00:00，當天新綁定或換綁帳號要等隔天才列入。私訊只顯示自己的今日成績；「#退出排行」可退出該群，解除綁定可退出全部群組。

清除雲端紀錄會刪除過去的每日成績，清空當天的分數、完成時間與分享色格，但保留帳號、日期、遊戲、首次開始時間及已清除標記，防止當天重玩；已清除的成績不列入排行，隔天可參加新的挑戰。標記也依 35 天保留規則清理；刪除帳號則一併刪除全部每日資料。

每日局也會記入一般遊玩紀錄、統計與成就；一般紀錄依原有最近 50 局規則保存，不會隨每日成績的 35 天清理而刪除。分享只包含完成秒數、踩地雷是否踩雷與翻翻樂失誤數，不包含盤面或答案。不主動推播，也不記錄一般群組聊天。

排行頭像

登入後可在「我的紀錄」挑一個 emoji 當排行頭像;沒挑過的人會依帳號固定配一個 emoji。這只保存你選的圖示與設定時間,不含照片。

「使用登入頭像」預設關閉。打開後,你在 LINE 群組排行(與日後的網站排行)會改顯示 Google 或 GitHub 登入時提供的大頭貼網址,其他玩家看得到。本站不下載或保存圖片本身,顯示時才從登入資料讀取網址;隨時可在「我的紀錄」關閉,關閉後立即改回 emoji。清除雲端紀錄或刪除網站帳號時,頭像設定一併刪除。

LINE 笑話、評分與投稿、小常識

使用 #笑話 時，會以你的 LINE 使用者識別碼保存看過的題目與時間，避免重複出題；全部看完後重新開始。評分保存題目、你的 LINE 使用者識別碼、1～3 分及評分時間，同一則只保留最後一次評分，用於近 30 天笑話排行。排行只顯示笑話、分類、平均分與人數，不顯示個人識別碼。

#投稿 會保存笑話內容、分類、LINE 使用者識別碼、投稿時間及審核結果；每日投稿上限 3 則，另保存日期與次數。投稿需經管理者審核才會上架，內容不能包含網址、電話或 email。投稿原文在群組中會被其他成員看到，審核通過的笑話可能公開回覆給其他使用者；後台與回覆不顯示完整投稿者識別碼。

玩家投稿的笑話,管理者審核時可看到投稿者登入帳號的顯示名稱(與「我的紀錄」相同)與你挑選的 emoji 頭像(未綁定者僅顯示識別碼末 4 碼);玩家端不顯示作者。審核時亦顯示該投稿者的累計投稿、上架與退回則數。

被下架或退回的笑話，30 天後連同評分與看過紀錄刪除，只保留無法還原內容的比對指紋（防止同一則重複投稿）。

使用 #小常識（或 #冷知識）時，會以你的 LINE 使用者識別碼保存看過的小常識與時間，避免重複出題；全部看過後重新開始，並與其他生活指令共用每日次數。#早安 附的「今日小常識」與 #晚安 附的「每日一笑」是全站同一則，不另外記錄你看過。

你可聯絡我們要求刪除看過紀錄（含小常識）、評分及投稿，請透過 LINE 私訊提出，勿在公開留言貼出識別碼。這些資料獨立於網站帳號，解除綁定或清除網站雲端紀錄不會自動刪除。資料庫無法使用時改回內建笑話，不保存備援出題或評分。

公事功能(測試)

第一次使用公事功能會詢問是否同意；不同意就不記錄你的公事指令，只記住你選了「不用」與時間以免重複詢問。你可隨時私訊 #公事退出，確認後停止記錄並刪除代稱（含各群組的代稱）、個人筆記、釘選與發給你的行事曆連結憑證；既有回報與其他事項保留到清除日。也可用 #公事同意 開始使用。

收集範圍是 # 開頭的公事指令與按鈕操作、選填代稱（可設一個預設代稱，也可在個別群組設只用於該群的代稱）、所屬專案、時間與來源群組名稱；不記錄群組一般聊天，也不記錄群組成員名單。在群組設定的代稱只會顯示在該群組；你離開該群組、bot 離開該群組、你私訊 #公事退出 或測試資料清空時刪除。已同意的成員在綁定專案的公事群組送出第一則回報後，會加入該專案，記錄加入途徑與群組名稱。

交辦、提醒、約只收錄 #交辦、#提醒、#約 開頭的指令與按鈕操作，不記錄一般聊天。被標記（@）的人會被記為事項對象，保存系統識別碼與發起人在該則指令打出的 @ 名稱，不記錄對象的發言；對象按按鈕前仍須同意。若 LINE 沒有提供對象識別碼，會先保留 @ 名稱，對象按鈕操作時才以當下群組成員顯示名稱比對認領；名稱不寫入其他名冊。

提醒與約不主動推播提醒。缺時間的提醒與約草稿 10 分鐘未設定會作廢，於後續互動判定；休閒群與私訊建立的提醒、約，在結束或取消 30 天後刪除（沒有互動時延後）。公事群事項依離開公事模式 30 天清除；收回原指令會刪除對應事項，試用結束一併清空。

加行事曆：按 [📅 加行事曆] 後會回一組連結，網址不含事項內容，只含隨機憑證與格式參數，7 天後失效。點開時才由伺服器產生行事曆檔案；知道連結就能開，7 天內任何拿到連結的人都能取得該則卡片的行事曆內容，請勿轉傳。每組連結最多讀取 20 次。

選 Google 行事曆時，事項標題與說明由你的瀏覽器送到 Google，儲存時進入你的 Google 帳號，依 Google 的隱私權政策處理；我們不會取得你的 Google 帳號資訊。選 .ics 檔並存進手機行事曆後，由你的裝置保管；我們不保存產生過的檔案。行事曆內容不含群組名稱與其他成員名單。改時間不會自動同步，請刪掉舊的再加一次。

連結憑證只保存雜湊，7 天到期後由後續互動分批刪除（沒有互動時會延後）；只記錄發給誰、發證時間、下載次數與最後下載時間以防濫用。我們的程式不記錄你的網路位址與連結憑證；但網站使用的雲端平台（Supabase）會依其政策保存存取紀錄（含完整連結與來源 IP、地區），只有本站管理者能查看。確認 #公事退出會刪除發給你的憑證，使該連結立即失效。取消或刪除事項後連結失效，測試清空會刪除憑證與限量計數。這是測試功能，行事曆會進入外部服務或裝置，正式使用前另行評估。

私訊待辦、筆記與釘選

私訊傳 #待辦，或傳 #早安、#晚安時，小集會整理與你有關的交辦、提醒、約與釘選給你看；包括你是對象、曾回應或發起的事項，依待辦規則判定。這些個人彙整只回覆本人，不在群組顯示，也不主動推播。來源群組名稱只在你的私訊中顯示；群組裡傳 #待辦 只會提示改用私訊。

離開群組後，該群事項不再列入你的彙整，重新加入後恢復；為此只記錄與你有事項往來的群組及離開時間，不建立群組成員名單。紀錄隨該群事項清除，或已無事項往來時於後續互動清除。

#記 只能在私訊使用，只有你自己看得到，管理者與網頁後台也看不到。每則最多 500 字、共 100 則，每天可新增 30 則；可查看最近十則、釘選或確認後刪除。筆記保存到本人刪除、收回原訊息、退出公事功能或試用結束清空為止；群組裡打 #記 不會收錄內容，只會提示改用私訊。

釘選最多五則，只影響自己的私訊顯示，不通知其他人；事項結束、刪除或不再與你相關時失效。筆記、釘選與待辦彙整不使用 AI。

被 @ 但系統對不上的對象，可在群組按鈕申請認領，由該則發起人確認；申請 24 小時到期，事項結束或對象已被綁定也會失效。群組只顯示代稱或發起人原先公開打出的 @ 名稱，沒有代稱的申請人顯示「一位成員」，不公開 LINE 顯示名稱或識別碼。

事項補充附圖

補充文字會依來源、訊息與段落順序分段保存，事項顯示原文與尚未收回的補充段；歷程只記每段前 40 字。收回補充文字訊息時，會刪除該段、重組事項內容，並清除該段在歷程中的文字摘要。收回原指令或清除事項時，補充段也會一併刪除。

交辦、提醒與約的發起人可在卡片按「補充」，開啟 2 分鐘收件窗；只收本人在同一群組或私訊傳的文字與照片，其他人的訊息、其他來源與窗外訊息不會併入事項。# 開頭仍當指令處理。每段文字最多 200 字，事項文字累計最多 1000 字；每件最多 3 張 JPEG／PNG 照片，每張上限 10 MB。開啟新的補充或回報附圖窗會關閉同一人的舊窗。

照片存放於私人儲存空間，只有管理者登入後台可查看；卡片與事件碼查詢只顯示「附圖 n 張」，不提供照片或下載網址。後台看圖網址 60 秒到期，頁面也會移除圖片。

事項補充照片在事項結束後 30 天清除；沒有結束時間的進行中交辦，保留到結案後 30 天或其他清除條件。取消事項、收回原指令或圖片、測試清空、群組離開公事模式滿 30 天清除時，會排入刪除。清除透過私人儲存服務執行，由後續互動或管理者按「立即清除到期附圖」觸發；沒有互動或刪檔失敗時會延後重試。

管理者切換群組模式、綁專案與清除資料會留下管理紀錄，不含聊天內容；這些紀錄不隨測試資料清空而刪除。群組中的公事卡片由該群組成員看得到；私訊只看自己的回報，管理者可查看全部。群組模式分為休閒群、工作群(含休閒)、純工作群,交辦與回報只在後兩種群組開放，提醒與約在休閒群也能使用；私訊可建立自己的提醒與約。回報與事項會有事件碼,可用 #查 查詢:群組內只查得到本群的事項,人名優先顯示代稱，對象沒有代稱時使用該則指令的 @ 名稱或「對象 n」;私訊只查得到與你相關的事項;草稿不會出現在群組查詢結果。

只開放在管理者指定的群組（最多 3 個）與受邀測試參與者，請只用專案代稱與假資料。請勿上傳真實公司資料、客戶資料、單號或含系統名稱的截圖。附圖請只用自製示意圖：在草稿卡按「📎 附圖」後，2 分鐘內只接收你在同一私訊或群組傳的 JPEG/PNG 圖片，每則最多 3 張、每人每天最多 20 張、單張最多 10 MB。目前不提供轉傳收集。

附圖存於私有儲存空間，只有管理者登入網頁後台後，透過有效 60 秒的簽名網址看圖；LINE 卡片與 CSV 只顯示「附圖 n 張」。你原本傳在 LINE 群組的圖片，群組成員仍可在 LINE 看到。

附圖保存 30 天，或標記已同步後 7 天，以先到者為準。收回圖片訊息、收回原回報、捨棄或作廢草稿、取消回報時即排入刪除並於當次處理刪檔；測試一鍵清空與群組離開公事模式滿 30 天清除也包含附圖。到期清除由後續互動或管理者按「立即清除到期附圖」觸發；沒有互動或刪檔失敗時會延後重試。

會保存回報描述、選擇的專案代稱、緊急程度、分類、處理狀態、備註與歷程、時間及來源（私訊或群組名稱），以及邀請加入的專案資格與每日回報次數。LINE 識別碼僅供系統辨識同一人，不顯示給他人；管理者查看時使用網站暱稱與 emoji 頭像，未綁定者僅顯示識別碼末 4 碼。

只有管理者可以查看與匯出全部回報；你可在私訊查看自己的進度。群組內的回報卡會讓該群組成員看到描述前段與選擇的欄位。這些資料不使用 AI 處理。

回報草稿最後操作後 60 分鐘作廢，於後續存取時刪除；群組離開公事模式 30 天後清除該群公事資料（由後續互動或管理者執行到期清除，沒有互動時會延後）；其餘回報文字與歷程保留到測試結束，屆時清空所有回報、專案、成員、群組綁定、同意與代稱。取消會保留文字及取消紀錄，直到測試結束。

你可收回原訊息，系統會連同整則回報與歷程刪除，不論處理狀態；「新的」狀態可在私訊確認取消，草稿可捨棄，也可請管理者協助刪除。去重與收回標記保留，以免重送恢復內容；刪除回報不重設當日上限。

我們不做的事

  • 不放廣告,不使用分析或追蹤工具。
  • 不分享、不出售你的資料給任何人。
  • 不讀取你的 GitHub 或 Google 帳號裡的其他資料。

使用的外部服務

  • GitHub Pages:放置網站。和一般網站一樣,GitHub 可能留有連線紀錄(例如 IP 位址)。
  • Supabase:登入與雲端資料庫,也用於接收及儲存 LINE 回饋。平台會依其政策保存存取紀錄(含完整網址與來源 IP、地區),只有本站管理者能查看。
  • GitHub、Google:只在你選擇用它們登入時,負責確認你的身分。
  • LINE:當你私訊官方帳號,或在機器人所在群組傳訊息時,會將事件轉送至接收端;一般群組聊天只在接收端暫時處理,不保存或記錄內容。

匯出與刪除

  • 匯出:在「我的紀錄」可以把紀錄匯出成檔案。
  • 清除雲端紀錄:登入後,在「我的紀錄」的帳號區塊按「清除帳號裡的雲端紀錄」,確認兩次後一併清除遊戲紀錄、自己送出的意見回饋、LINE 綁定與群組排行、排行頭像設定、網站今日排行的公開設定與暱稱;當天每日挑戰保留首次開始時間與已清除標記，不能重玩，詳見上方「每日挑戰」。這台裝置上的紀錄不受影響。
  • 刪除登入身分:帳號本身(登入服務裡的帳號資料)需要由我們刪除,請到下方聯絡方式提出,我們會在 30 天內處理。
  • 只用本機時:清除瀏覽器的網站資料即可。

兒童使用

遊戲本身不需要登入。小朋友若要登入,建議由家長陪同,使用家長同意的帳號。
