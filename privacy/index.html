隱私權政策

最後更新:2026-10-13

簡單說

  • 不登入也能玩,紀錄只存在你自己的瀏覽器裡。
  • 登入可讓不同裝置看到同一份紀錄,也可送出意見回饋;會用到你的顯示名稱、頭像、遊戲紀錄與你送出的意見。
  • 不放廣告、不做追蹤,也不會分享或出售你的資料。

沒有登入時

遊戲紀錄(分數、最佳紀錄、經驗值、成就、進行中的存檔)和設定(深淺色、難度)只存在這台裝置的瀏覽器儲存空間,不會傳到任何伺服器。清除瀏覽器的網站資料,這些紀錄就會一起清掉。

登入後

你可以用登入畫面提供的 GitHub 或 Google 帳號登入。登入後:

  • 我們使用的資料:登入帳號提供的顯示名稱與頭像(顯示在「我的紀錄」),以及你的遊戲紀錄。
  • 存在哪裡:遊戲紀錄存在 Supabase 雲端資料庫(資料中心位於南韓首爾)。資料庫設定成每個帳號只能讀寫自己的紀錄。
  • Email:登入服務(Supabase 的帳號系統)會記錄你登入用的 email,用來辨認是同一個帳號;遊戲集錦本身不把 email 存進遊戲紀錄,也不會顯示或使用它。
  • 登入狀態:為了不必每次重新登入,登入憑證會存在這台裝置的瀏覽器;登出時刪除。

意見回饋

網站管道需登入後才能送出意見回饋。我們會儲存回饋內容、類型、遊戲、版本、網址路徑、裝置類型(手機、平板或電腦)與時間,並和你的帳號連結,用來改善遊戲。除了你可在「我的紀錄」看到自己送出的意見與狀態,只有管理者能查看全部回饋與送出者的顯示名稱。

回饋不另存 email、IP 或瀏覽器指紋;網址只記路徑,不記查詢參數。請不要在內容中填入 email 或其他個人資料。為防止大量送出,資料庫另保留每個帳號最近送出時間與當日次數,不保留額外的回饋內容;清除回饋不會重設當日上限。

你可以在「我的紀錄」清除自己的回饋,或到下方 GitHub Issues 要求刪除。

LINE 管道

指令與對話範例請看LINE 小幫手使用說明。

私訊官方帳號的文字除遊戲、綁定、成績、排行、生活指令、取消詞及整則無井號的「早安」「午安」「晚安」外都視為回饋;群組或多人聊天室只有在管理者核准後,才收取以「#回饋」或「＃回饋」開頭的文字。關鍵字後需接空白、換行或結尾,空內容不保存。文字最多保存 1000 字,超過會截斷並標示。圖片、貼圖、影片、語音與檔案目前不收,不下載也不保存。

LINE 生活指令(#天氣、#早安、#午安、#晚安)會依你的 LINE 使用者識別碼記住私訊上次查詢的縣市,不記錄其他訊息內容;另保留每日使用次數與事件識別碼以限制用量和避免重複回覆,只在你發出指令時回覆,不主動推播。

我們會儲存回饋文字、管道、類型、處理狀態與時間,以及 LINE 使用者識別碼、群組或聊天室識別碼、訊息識別碼、來源類型與顯示名稱快照,用來改善遊戲。LINE 回饋與來源資料只有管理者看得到;回饋本身不和網站帳號綁定,不出現在「我的紀錄」。不記錄一般群組聊天;未核准群組出現指令或成員加入事件時,只保存群組或聊天室識別碼與首次／最後時間,供管理者核准。

你可在 LINE 收回原訊息,系統收到收回事件後會刪除回饋、來源與處理歷程;也可請管理者刪除,透過下方 GitHub Issues 提出時請勿公開個人識別碼。為避免重送讓已收回內容復原,系統會保留不含內容的事件去重及收回識別碼;每日配額只保存識別碼、日期與次數,刪除回饋不重設配額。

LINE 綁定與群組排行

私訊「#綁定」可取得 10 分鐘內有效的一次性連結;資料庫只保存代碼的 SHA-256 雜湊、LINE 使用者識別碼、顯示名稱、到期與使用時間。登入網站並按「確認綁定」後,保存 LINE 使用者識別碼、網站帳號識別碼、LINE 顯示名稱快照與綁定時間。一個 LINE 和網站帳號各只能綁定一個對象;重新綁定會取代原綁定並退出原有排行。不要分享綁定連結。

私訊「#成績」可以看自己的等級、XP、總局數與最佳分數。在已核准群組使用「#成績」時,自己的成績卡會公開給該群組成員。

群組排行只列出自己在該群打「#加入排行」的人,保存群組識別碼、LINE 使用者識別碼、顯示名稱快照與加入時間。各群獨立,顯示近 7 天 XP 或指定遊戲的最佳分數前 10 名;XP 依每人最近 50 局紀錄計算,可能不涵蓋七天全部遊玩。下指令或加入排行時會更新顯示名稱快照。

在群組打「#退出排行」可退出該群;私訊「#解除綁定」或在「我的紀錄」按「解除 LINE 綁定」,會同時退出所有群組排行。清除雲端紀錄或刪除網站帳號也會清除綁定與排行。一般聊天不記錄,綁定成功不另發通知或主動推播。

我們不做的事

  • 不放廣告,不使用分析或追蹤工具。
  • 不分享、不出售你的資料給任何人。
  • 不讀取你的 GitHub 或 Google 帳號裡的其他資料。

使用的外部服務

  • GitHub Pages:放置網站。和一般網站一樣,GitHub 可能留有連線紀錄(例如 IP 位址)。
  • Supabase:登入與雲端資料庫,也用於接收及儲存 LINE 回饋。
  • GitHub、Google:只在你選擇用它們登入時,負責確認你的身分。
  • LINE:當你私訊官方帳號,或在機器人所在群組傳訊息時,會將事件轉送至接收端;一般群組聊天只在接收端暫時處理,不保存或記錄內容。

匯出與刪除

  • 匯出:在「我的紀錄」可以把紀錄匯出成檔案。
  • 清除雲端紀錄:登入後,在「我的紀錄」的帳號區塊按「清除帳號裡的雲端紀錄」,確認兩次後一併清除遊戲紀錄、自己送出的意見回饋、LINE 綁定與群組排行;這台裝置上的紀錄不受影響。
  • 刪除登入身分:帳號本身(登入服務裡的帳號資料)需要由我們刪除,請到下方聯絡方式提出,我們會在 30 天內處理。
  • 只用本機時:清除瀏覽器的網站資料即可。

兒童使用

遊戲本身不需要登入。小朋友若要登入,建議由家長陪同,使用家長同意的帳號。

聯絡我們

有任何問題,或要刪除登入身分,請到 GitHub Issues 提出(需要 GitHub 帳號)。請不要在公開的留言裡寫出 email 或其他個人資料,我們會在留言串回覆你。

政策更新

這份政策有變動時會更新本頁,並修改上方的「最後更新」日期。
