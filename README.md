# 遊戲集錦 Game Collection

純 HTML/CSS/JS 的網頁小遊戲合集,打開就能玩,不需要安裝。

**線上遊玩:https://phearman.github.io/game-collection/**

| 遊戲 | 狀態 |
|------|------|
| 2048 | ✅ 可玩 |
| 踩地雷 | 規劃中 |
| Wordle(英文) | 規劃中 |
| 井字棋 + AI | 規劃中 |
| 數獨 | 規劃中 |
| 貪食蛇 | 規劃中 |

每款遊戲右上角都有「? 玩法」,第一次進入會自動顯示規則與示範。

本 repo 僅包含發佈用的網站檔案;開發在另一個 repo 進行。
